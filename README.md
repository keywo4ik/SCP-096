# SCP-096 — Лабиринт

3D-игра от первого лица в браузере: бетонный лабиринт, SCP-096(скромник), порталы и вечерняя атмосфера.

## 🎮 Играть

**[Открыть игру →](https://keywo4ik.github.io/scp096/)**

## 🕹 Управление

- **Телефон**: левый джойстик — движение, свайп справа — обзор
- **ПК**: WASD + мышь

## 🎯 Цель

Найдите выход (зелёное свечение у бетонной вышки в правом верхнем углу карты).
- 🔴🟢🔵 Красный, синий, зелёный порталы → ведут к выходу
- Остальные порталы — ложные, телепортируют в случайное место
- **Не смотрите на SCP-096** — иначе он впадёт в ярость

## 🛠 Технологии

- [Three.js](https://threejs.org/) 0.160 (CDN)
- Web Audio API — все звуки генерируются в реальном времени, без аудиофайлов
- Один HTML-файл, без сборки
